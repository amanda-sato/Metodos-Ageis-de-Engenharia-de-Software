Versão 1:

PLATAFORMA DE BASE DE DADOS DE CURRÍCULOS PARA ESTÁGIO.

1.	Como aluno, quero poder me registar na plataforma, para que possa registar meus currículos.
2.	Como aluno, quero registar meus currículos na plataforma, para que possa me candidatar a vagas de empresas diversas.
3.	Como aluno em busca de estágio, quero poder visualizar as vagas ofertadas por empresas, para que possa verificar quais vagas poderiam ser do meu interesse.
4.	Como aluno, quero poder ter diversos currículos registado na plataforma, para conseguir adequar melhor a cada vaga, inclusive com outras línguas.
5.	Como aluno, quero poder ocultar currículos específicos, para que as empresas não possam visualizar aquele currículo. 
6.	Como aluno, quero remover um currículo da plataforma, para que ele seja excluído da base de dados.
7.	Como aluno, quero poder procurar vagas com base em filtros específicos, para facilitar a minha busca.
8.	Como aluno, quero que os outros alunos-candidatos não sejam capazes de visualizar meu currículo, para manter minha privacidade.
9.	Como aluno, quero poder atualizar minhas informações da minha conta, para que esteja sempre atualizada.
10.	Como aluno, quero poder excluir minha conta, para que quando não precisar mais, meus dados não fiquem no sistema.


Versão 2:

PLATAFORMA DE BASE DE DADOS DE CURRÍCULOS PARA ESTÁGIO.

1.	Como aluno à procura de estágio, quero criar uma conta na plataforma, seja utilizando login social ou preenchendo um formulário, para que possa candidatar-me a vagas e gerir os meus currículos em um só lugar.
2.	Como aluno, quero adicionar currículos ao meu perfil indicando a língua de cada um, para que possa adaptar a candidatura ao tipo de vaga e ao País da empresa.
3.	Como aluno, quero visualizar as vagas de estágio publicadas pelas empresas, para que possa identificar oportunidades do meu interesse e alinhadas com meu perfil.
4.	Como aluno, quero utilizar filtros para procurar por vagas de acordo com área, localização, modalidade (presencial, remoto ou híbrido) e duração, para que encontre as vagas adequadas ao meu perfil e condizentes com meu interesse.
5.	Como aluno, quero me candidatar a uma vaga escolhendo qual dos meus currículos enviar, para que concorra com a versão que julgo mais adequada àquela vaga.
6.	Como aluno, quero ocultar ou tornar visível cada um dos meus currículos, para que possa decidir quais dos currículos as empresas podem consultar.
7.	Como aluno, quero que os meus currículos nunca sejam visíveis para outros alunos, para que os meus dados pessoais e privacidade fiquem protegidos.
8.	Como aluno, quero deletar um currículo que já não uso, para que versões desatualizadas não sejam vistas pelas empresas e não constem na base de dados da plataforma.
9.	Como aluno, quero atualizar os meus dados pessoais e de contato, para que as empresas consigam me contatar.
10.	Como aluno, quero eliminar a minha conta a qualquer tempo, para que os meus dados pessoais deixem de ser guardados quando já não precisar da plataforma.
