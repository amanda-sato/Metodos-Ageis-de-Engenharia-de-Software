PLATAFORMA DE BASE DE DADOS DE CURRÍCULOS PARA ESTÁGIO.

1.	Como aluno, quero poder me registar na plataforma, para que possa registar meus currículos.
2.	Como aluno, quero registar meus currículos na plataforma, para que possa me candidatar a vagas de empresas diversas.
3.	Como aluno em busca de estágio, quero poder visualizar as vagas ofertadas por empresas, para que possa verificar quais vagas poderiam ser do meu interesse.
4.	Como aluno, quero poder ter diversos currículos registado na plataforma, para conseguir adequar melhor a cada vaga, inclusive com outras línguas.
5.	Como aluno, quero poder ocultar currículos específicos, para que as empresas não possam visualizar aquele currículo. 
6.	Como aluno, quero remover um currículo da plataforma, para que ele seja excluído da base de dados.
7.	Como aluno, quero poder procurar vagas com base em filtros específicos, para facilitar a minha busca.
8.	Como aluno, quero que os outros alunos-candidatos não sejam capazes de visualizar meu currículo, para manter minha privacidade.
9.	Como aluno, quero poder atualizar minhas informações da minha conta, para que esteja sempre atualizada.
10.	Como aluno, quero poder excluir minha conta, para que quando não precisar mais, meus dados não fiquem no sistema.
